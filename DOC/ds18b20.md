# Overview

The DS18B20 module provides temperature measurement using one or more DS18B20 sensors connected to a shared 1-Wire bus.

The firmware automatically detects connected sensors during startup.

---

# Features

Current implementation:

- Multiple DS18B20 sensors
- Automatic sensor discovery
- Automatic ROM identification
- Temperature measurement
- REST API
- MQTT status
- Web Dashboard

---

# Hardware

| Parameter | Value |
|-----------|-------|
| Interface | 1-Wire |
| GPIO | GPIO7 |
| Sensor | DS18B20 |

---

# Sensor Discovery

During startup the firmware:

1. Initializes the 1-Wire bus.
2. Searches for connected sensors.
3. Stores detected ROM addresses.
4. Starts periodic temperature measurements.

No manual sensor configuration is required.

---

# Sensor Identification

Each sensor is identified by its unique ROM code.

Example:

```
288F210D090000
28FFB4A5311703
```

The firmware reports the ROM address **without the CRC byte**.

This shorter identifier is sufficient to uniquely distinguish sensors and improves readability.

---

# Temperature Measurement

Current implementation:

- Unit: °C
- Floating point resolution
- Periodic measurement
- Automatic update of runtime state

---

# REST API

Temperature data is available through:

```http
GET /api/status
```

Example:

```json
"temperature":
{
    "count":2,
    "sensors":
    [
        {
            "address":"288F210D090000",
            "present":true,
            "value":25.875
        }
    ]
}
```

---

# MQTT

Temperature data is included in:

```
<device_name>/status
```

No dedicated temperature topic is currently used.

---

# Web Dashboard

The dashboard displays:

- number of detected sensors
- sensor identifier
- current temperature
- online status

The displayed values are automatically refreshed.
